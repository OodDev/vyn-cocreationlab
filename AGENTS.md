# Agent notes

## What this repo is

Static-export portfolio for **VYN – CoCreation Lab** (see `README.md` for the
full picture). Next.js 16.4.2 with `output: "export"`, React 19.3.1, Tailwind v4.
**Static export:** no server features (no route handlers, no ISR,
no Next image optimization server-side — imagery ships via `out/`).

## Workflow

- `npm run dev` for local work; `npm run build` regenerates assets/`llms.txt`
  first, then exports; `npm run preview` serves `out/` on :3000.
- `npm run lint`, `npm run typecheck`, `npm run format` exist — run them when
  touching shared code.
- Generated files, regenerated by build, never commit by hand: `public/images`,
  `public/favicon`, `public/og`, `llms.txt` mirrors.

## Conventions

- **Scratch stays out of git**: root `*.html`, `*.mp4`, `*.png`, `*.jpg`
  design experiments (incl. one-off shot dirs like `parallax-shots/`,
  `hero-variants-shots/`) are intentionally untracked; keep it that way.
- Only the one design source image `main-bg_UPSCAL.png` is tracked on purpose.
- Commit messages: descriptive, describe the interaction/visual change
  (see `git log` for the established style).
- Do not edit the `nextjs-agent-rules` block above — `next dev` rewrites it.
